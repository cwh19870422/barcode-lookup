管理客戶

新增、匯入、匯出客戶名單

← 回到主頁

1新增單一客戶

2匯入 Excel（選填）

欄位需包含：姓名、電話、地址、會員等級（A/B/C/D）、統編、備註。可一次匯入多筆，會加到下方清單中。

拖曳 Excel 檔案到這裡，或點擊選擇檔案
支援 .xls / .xlsx

3目前清單（可直接編輯／刪除）

4上傳到 GitHub

1. 打開你的 GitHub repo 頁面
2. 找到 customers.json（如果是第一次，用「Add file → Upload files」新增；已存在的話點進去用鉛筆編輯或直接上傳覆蓋）
3. 選擇剛剛下載的新 customers.json，上傳並覆蓋
4. 填寫 commit 訊息，點 Commit changes
5. 等 30 秒到 1 分鐘，主頁「客戶」分頁和「打單」分頁就會顯示最新的客戶名單，網址不變。
