每筆交易按「列印A4帳單」或「儲存交易」時，會自動存進 GitHub 倉庫的 transactions/ 資料夾（每月一個檔案，並有完整版本備份），開啟網站時自動讀取。
  1. 到 GitHub 右上角頭像 → Settings → 最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 選 Only select repositories，只勾 barcode-lookup
  3. Repository permissions 找到 Contents，改成 Read and write（其他都不要開）
  4. 有效期限選最長，按 Generate token，複製以 github_pat_ 開頭的那串，貼到下面
這組金鑰只能操作 barcode-lookup 這個倉庫，只存在你按儲存的這台裝置，不會寫進網站程式碼。每台要用的裝置（電腦、手機）都要各貼一次。
